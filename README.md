# Хайку на NFC-метке

Одна страница, два режима. Без хэша — композер: вводишь хайку, получаешь URL для метки NTAG216
и команды для включения счётчика прочтений. С хэшем — читалка: хайку и номер прочтения.
Текст целиком хранится в метке, страница ничего не хранит и не отправляет.

Читалка: https://liquidlo.github.io/haiku/
