# Хайку на NFC-метке

Композер для меток NTAG216. Текст хайку хранится в самой метке двумя NDEF-записями:

1. `sms:?&body=…` — iPhone при прикладывании открывает хайку как черновик сообщения, без приложений и без сети;
2. обычный Text — для Android и любых NFC-читалок, в дампе памяти читается как есть.

Счётчик прочтений чипа зеркалится в конец текста; композер считает нужную страницу памяти и команды для NFC Tools.
