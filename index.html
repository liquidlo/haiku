Хайку на метке

Текст хранится в самой метке. iPhone при прикладывании открывает его как черновик сообщения, без приложений и без сети. Любая NFC-читалка и Android видят его как обычный текст.

1. Запись URL/URI

Открыть на этом устройстве

2. Запись Text, язык ru

3. Записать метку

  1. NFC Tools → Write → Add a record → URL/URI, вставить ссылку из пункта 1 целиком, вместе с sms:. Не выбирать тип «SMS», он требует номер.
  2. Add a record → Text, язык ru, вставить текст из пункта 2. Порядок важен: URL первым.
  3. Нажать Write, приложить метку. Потом Read и убедиться, что обе записи на месте.

4. Включить счётчик

  1. NFC Tools → Other → Advanced NFC commands. Прочитать настройки: 30 E3. На чистой метке ответ начинается с 04 00 00 FF.
